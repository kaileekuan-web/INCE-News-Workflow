# Frontier labs & big tech — EXCLUDED from the general AI news report.
#
# The general news report is about smaller AI startups. Anything on this list is
# already covered everywhere else, so it is filtered out of the news table (the
# funding tables are unaffected — a frontier lab investing in a startup is still
# a startup story).
#
# FORMAT — one lab per line:
#
#   Display Name: alias, another alias, @handle, domain.com
#
#   @handle    an X account. A post BY this account is dropped outright.
#   domain.com a website. An article on this domain is dropped outright.
#   alias      a plain word/phrase (company, product or founder name). Dropped
#              when it is the SUBJECT of the story — i.e. it appears in the
#              opening of the headline. A passing mention further in ("built on
#              GPT-5", "ex-OpenAI founders") does NOT drop the story, because
#              those are exactly the startup stories we want to keep.
#
# Matching is case-insensitive and whole-word, so "meta" won't match "metadata"
# and "ai21" won't match "ai2100". Multi-word aliases match as phrases.
#
# Edit freely: delete a line to let that company back into the report, add a
# line to exclude another. `collect_x.py --include-frontier` and
# `generate_ai_doc.py --include-frontier` bypass this file entirely.
